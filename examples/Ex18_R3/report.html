Lateral system & load path

The lateral force-resisting system is a steel concentrically braced / dual in each principal direction. Gravity path: floor/roof pressure → floor beams (two-way tributary) → girders/columns → column bases → foundation. Lateral path: story inertial/wind force → rigid floor diaphragm → vertical lateral frames → column bases → foundation, in both orthogonal directions. Reviewer acceptance items

  • Combinations applied to the right members (Ω0 to capacity-protected only); uplift/net-tension (0.9D) checked.

The analysed set is the ASCE 7-22 §2.3 LRFD strength combinations:

  • Vertical seismic Ev = 0.2·SDSD = 0.04D is folded into the D factor: seismic combinations use (1.2+0.2SDS)D = 1.24D and (0.9−0.2SDS)D = 0.86D.
  • Redundancy ρ = 1.0 multiplies the horizontal seismic effect QE (§12.3.4).
  • Overstrength Ω0 = 3.0: the columns-only cases apply Em = Ω0QE to the capacity-protected columns (§12.4.3) and are not applied to other members.
  • Directional 100/30: each seismic case carries 100% of Fx in the loaded direction plus 30% in the orthogonal direction (§12.5.3/12.5.4).
  • Accidental torsion ±Mt = ±0.05B·Fx (§12.8.4.2) is applied in both signs.
  • Net uplift / overturning is checked by the 0.9D combinations (minimum gravity with lateral).
  • Second order: every combination is solved independently through a P-Δ analysis; factored second-order results are never superposed.
